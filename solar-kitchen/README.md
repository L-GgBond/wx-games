# 节气厨房 · solar-kitchen

跟着二十四节气做当季的菜：客人点一道，从三样当季食材里挑对两样，下锅掌火。

## 怎么跑

| 场景 | 操作 |
|---|---|
| 浏览器预览 | 直接打开 `index.html`（`game.js` 已入库） |
| 微信小游戏 | 微信开发者工具导入本目录，`compileType` 已是 `game` |
| 改代码 | `npm install` → `npm run watch` |
| 自检 | `npm run check`（`tsc --noEmit` + 构建 + 逻辑回归） |

## 玩法与数值

| 规则 | 数值 | 改哪里 |
|---|---|---|
| 关卡 | 24 个节气，每关 3 张订单 | `src/logic.ts` → `TERMS` |
| 食材 | 每个节气 3 样，订单固定取两两组合，一关三单不重样 | `dishOf` |
| 价格 | `12 + 节气序号 × 2`，再乘 1.0~1.24 的系数 | `dishOf` |
| 火候区 | 完美 ±6%，不错 ±20%，其余算糊 | `PERFECT_HALF` / `GOOD_HALF` |
| 收入 | 完美 ×1.6 / 不错 ×1 / 糊 ×0.4 | `rewardOf` |
| 指针速度 | `0.55 + 节气×0.02 + 年份×0.15`，有上限 | `heatSpeed` |
| 循环 | 走完 24 个进第二年，食材不变、火候更快 | `nextTerm` |

改 `TERMS` 就能换一整套食材和菜名（菜名由 `清炒/慢炖/凉拌/煨汤/小炒/焖` + 两样食材拼出来，动词按名字哈希固定，同一道菜永远同一个名字）。

## 目录

| 文件 | 作用 |
|---|---|
| `src/logic.ts` | 纯逻辑：节气表、配方、火候判定、收入星级、分享码 |
| `src/scenes.ts` | 首页 / 灶台 / 火候面板 / 结果 / 节气结算 |
| `src/art.ts` | 食材（叶 / 根 / 果三种外形）、锅、蒸汽、火候条、盘子 |
| `src/ui.ts` | immediate-mode 按钮 / 文本 / 点击热区 |
| `src/platform.ts` | 微信与浏览器双端适配、激励视频 |
| `src/storage.ts` | 最高节气、最高营收、引导标记 |
| `src/social.ts` | 微信侧离屏 Canvas 分享卡片 |
| `verify.mjs` | 59 条断言：节气数据完整性、火候边界、出餐结算 |

## 已知取舍

- 没有「客人耐心」倒计时：这类小游戏的主力用户是碎片时间打开，催时间会劝退，压力全部放在火候条上。
- 糊了也照样出餐、照样给钱（×0.4），订单不会卡住，避免一局做废。
- 火候判定加了 `1e-9` 的 epsilon：`0.56` 这种浮点误差不会把完美判成不错。
